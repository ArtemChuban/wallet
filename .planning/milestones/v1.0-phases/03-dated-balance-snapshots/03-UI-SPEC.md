## Color

Light theme tokens — **inherited from Phase 02** (`src/app/globals.css` `:root`):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`--background`) | Page background, dialog surface, account row default |
| Secondary (30%) | `#F5F5F5` (`--muted` / `--secondary`) | Top nav, row hover, **expanded history panel background** (`bg-muted/40` or muted fill) |
| Accent (10%) | `#1A1A1A` (`--primary`) | Reserved elements only (see below) |
| Destructive | `#C4473A` (`--destructive`) | History **Удалить** control text/icon; field `aria-invalid` / error text; confirm destructive affordance |

Accent reserved for:
1. Primary CTA buttons («Задать первый баланс», dialog «Сохранить баланс», existing «Добавить счёт» / «Сохранить»)
2. Active nav link underline/foreground emphasis
3. Focus ring companion (`--ring`) on focused controls
4. Phase 02 «Основная» badge (unchanged)

Do **not** use accent for: every list row, borders, expand chevrons, plain history rows, or decorative icons.

Destructive reserved for: snapshot delete control + its confirmation; validation error text. Never for set-balance primary submit.

Foreground: `--foreground` ≈ `#0A0A0A`. Muted meta (as-of date, «долг» secondary line): `--muted-foreground` ≈ `#737373`.

Sources: Phase 02 UI-SPEC; destructive now used for delete (D-11).

### Set-balance Dialog

| Dialog | Title |
|--------|-------|
| Non-credit set balance | Задать баланс |
| Credit set balance | Задать доступный лимит |

| Field | Label |
|-------|-------|
| Amount (non-credit) | Баланс |
| Amount (FIAT_CREDIT) | Доступный лимит |
| As-of date | Дата |

Credit dialog hint (Label/muted under amount): «Остаток лимита — сколько ещё можно потратить. Долг = лимит − доступно.»

Date input: default **today** (D-03); `max` = today; past allowed; future forbidden (D-12).

Same-date overwrite: no extra confirm in dialog — upsert is intended (D-09). Optional muted hint when date already has a snapshot is discretionary; not required.

### Account row LOCF display (populated)

| Account type | Display pattern |
|--------------|-----------------|
| Non-credit | `{amount} {CODE}` · `на {DD.MM.YYYY}` |
| FIAT_CREDIT | `доступно {available} {CODE}` · `долг {debt} {CODE}` · `на {DD.MM.YYYY}` |

Date display format **DD.MM.YYYY** (Russian-first). Form value remains `YYYY-MM-DD`.

Never show raw minor BigInt. Never show `0.00` when LOCF is null.

### Snapshot history (expanded)

| Element | Copy |
|---------|------|
| Expand control aria-label | Показать историю балансов |
| Collapse control aria-label | Скрыть историю балансов |
| History section label (optional) | История |
| Non-credit history row | `{DD.MM.YYYY}` · `{amount} {CODE}` |
| Credit history row | `{DD.MM.YYYY}` · `{available} {CODE}` (available only — D-16) |
| Delete control label | Удалить |
| Delete control aria-label | Удалить снимок за {date} |

Order: newest first (D-14). No «текущий» marker on history rows (D-15).

## Interaction & Layout Contract

| Decision | Contract |
|----------|----------|
| Routes | Extend `/accounts` only. **No** `/balances`, **no** `/accounts/[id]` (D-01) |
| Set balance | Per-row Dialog: amount + as-of date (D-01). Remount form on open (`formKey`) like AccountFormDialog |
| Default date | Today in app calendar TZ (`Europe/Moscow` per 03-RESEARCH A3); pass as prop from server |
| First balance | Emphasized accent Button «Задать первый баланс» in row balance slot when LOCF null (D-04) |
| Current LOCF | Row shows LOCF-as-of-today amount(s) + producing snapshot date (D-02, D-08) |
| Credit input | User enters available remaining only; debt derived on read — never an input (D-05–D-07) |
| History | Inline expand under account row (`useState`); not Sheet/Dialog history (D-13) |
| Expand affordance | Ghost icon Button + lucide `ChevronRight` (collapsed) / `ChevronDown` (expanded); 44×44 tap target |
| Delete | Only on history rows (D-11); never inside set-balance Dialog. Confirm before delete (copy above) |
| Pending submit | Disable primary button; keep Dialog open until success then close + `revalidatePath("/accounts")` |
| Pending delete | Disable that row’s delete control while action pending |
| Money I/O | Major decimal string ↔ `parseMajorToMinor` / `formatMinorToMajor` with account currency scale |
| BigInt boundary | Serialize `amountMinor` / derived debt / limits as strings to client components |
