## Spacing Scale

Declared values (must be multiples of 4) — **inherited from Phase 02 / 05**:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, range button internal gaps |
| sm | 8px | Compact gaps: range control to chart, toggle to chart |
| md | 16px | Default element spacing; chart section horizontal padding match list |
| lg | 24px | Gap between hero block and chart section; gap between chart section and account list |
| xl | 32px | Page `gap-8` main rhythm (`max-w-3xl` shell) |
| 2xl | 48px | Major break only if partial banner + chart both present (banner→chart) |
| 3xl | 64px | Not used |

Exceptions:
- Minimum tap target **44×44px** for range preset Buttons and expand chevron control (`min-h-11` / padded hit area — match Phase 04 rate direction chips).
- Chart container height **200px** fixed (`h-[200px] w-full` on `ChartContainer`) — NW and per-account charts (06-RESEARCH pitfall 3).
- Account expand body: **16px** (md) padding inside expanded panel (`px-4 py-4`); panel `bg-muted/40` matching Phase 03 history expand.
- Account list row: **12px** vertical (`py-3`) × **16px** horizontal (`px-4`) — unchanged from Phase 05.
- Range control: **8px** (sm) gap between preset Buttons; **16px** (md) margin below control before chart.

Source: Phase 05 UI-SPEC; 06-CONTEXT D-03; 06-RESEARCH chart height.

|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.5 |

Usage (Phase 06 extensions):

- **Label** — range preset Buttons; native/primary toggle; chart axis ticks; tooltip lines; legend for credit stack («долг» / «доступно»); expand aria labels.

- **Heading** — not required for charts; optional «Счета» list header unchanged.

Axis tick and tooltip amounts: Geist Mono at Label (14px). Selected range Button: weight **600**; unselected: **400**.

Sources: Phase 05 UI-SPEC; 06-CONTEXT discretion (Russian labels).

## Color

Light theme tokens — **inherited from Phase 02 / 05** (`src/app/globals.css` `:root`):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`--background`) | Page background, list surface, chart plot background |
| Secondary (30%) | `#F5F5F5` (`--muted` / `--secondary`) | Top nav; expand panel `bg-muted/40`; unselected range Button; hover |
| Accent (10%) | `#1A1A1A` (`--primary`) | Reserved elements only (see below) |
| Destructive | `#C4473A` (`--destructive`) | Not used on charts (no delete). Phase 05 partial banner rules unchanged |

**Chart series tokens** (CSS variables already in `globals.css` — prefer mid/dark for stroke contrast on white):

| Series | Token | Usage |
|--------|-------|-------|
| NW line | `var(--chart-3)` | Stroke for net-worth LineChart (`ChartConfig` key `nw`) |
| Account line (non-credit) | `var(--chart-3)` | Native or primary single series |
| Credit debt stack | `var(--chart-5)` | Area fill `debt`, `stackId="credit"` |
| Credit available stack | `var(--chart-2)` | Area fill `available`, `stackId="credit"` |
| Grid / axis | `var(--border)` / `var(--muted-foreground)` | `CartesianGrid`; tick labels `text-muted-foreground` |

Do **not** use `--chart-1` as sole stroke on light backgrounds — too light (`oklch(0.87)`); reserved unused or for optional fill under NW area if executor adds Area later (v1 = Line only for NW).

Accent reserved for:
1. Selected range preset Button (`default` / primary variant)
2. Active top-nav «Главная»
3. Focus rings on range, toggle, expand controls
4. Empty-dashboard CTA «Перейти к счетам» (Phase 05 — unchanged)

Do **not** use accent for: every chart stroke (use `--chart-*` above), hero amount, or partial-warning fill.

Foreground: `--foreground` ≈ `#0A0A0A`. Muted meta: `--muted-foreground` ≈ `#737373`.

Sources: Phase 05 UI-SPEC; `globals.css` `--chart-1`…`--chart-5`; 06-RESEARCH; contrast discretion.

## Copywriting Contract

All chrome Russian. Currency codes stay Latin. Amounts via `formatMinorToMajor` + code; dates via `formatAsOfDisplay` (DD.MM.YYYY). Never raw BigInt in UI.

| Element | Copy |
|---------|------|
| Primary CTA | **30д** — default selected shared range preset (D-06); primary interaction is changing range, not a link |
| Empty chart (no points) | **No copy block** — render axes with zero points only (D-13). Do not show «Нет данных» overlay |
| Empty dashboard (zero accounts) | Unchanged Phase 05: heading «Нет счетов» / body «Создайте первый счёт, чтобы увидеть капитал.» / CTA «Перейти к счетам» — **omit** chart section when zero accounts |
| Error state (page DB) | Unchanged: «Не удалось загрузить данные. Проверьте базу данных и обновите страницу.» |
| Destructive confirmation | none — charts read-only (D-04) |

### Range presets (shared — D-05, D-08)

| Preset id | Button label |
|-----------|--------------|
| `30d` | 30д |
| `90d` | 90д |
| `1y` | 1г |
| `all` | всё |

Default selected: **30д**. One selection at a time. `aria-pressed` on active Button. Group accessible name: **Период**.

### Native ↔ primary toggle (per-account — D-09, D-10)

| Element | Copy |
|---------|------|
| Native mode | В валюте счёта |
| Primary mode | В {PRIMARY} — e.g. «В RUB» |
| Hide when | Account currency is primary — do not render toggle (D-10) |
| Default | Native |

### Expand affordance (D-02, D-04)

| Expand body | Chart only — no «История», no set/delete |

### Chart chrome / tooltips

| Element | Copy |
|---------|------|

Hero «Капитал», partial banner «Итог неполный», list columns, credit row list copy, nav — keep Phase 05 strings.

## Interaction & Layout Contract

| Decision | Contract |
|----------|----------|
| Route | `/` only — no `/history` (D-01 deferred) |
| Layout order | **Hero («Капитал») → partial banner (if any, Phase 05) → shared range + NW chart → account list** (D-03) |
| Page shell | Unchanged: `main` `mx-auto w-full max-w-3xl flex-1 flex-col gap-8 px-4 py-8` |
| Shared range | Client `useState` default `"30d"` in `DashboardChartsShell` — **not** URL/searchParams, **not** cookie (06-RESEARCH Pattern 3) |
| NW chart | LineChart, primary major Y, sparse event∪today points (D-07); `type="linear"`; `connectNulls={false}`; `dot={data.length <= 1}` (D-15) |
| Empty NW / account series | Always mount axes; empty `data=[]` → Y domain `[0, 1]`, X ticks = window start + today labels (D-13) |
| Single point | Show dot(s); **no** connecting line/area segment (D-15) |
| Account expand | Chevron on row; body = `AccountHistoryChart` only (D-02, D-04) |
| Account non-credit | LineChart native or primary per toggle |
| Account credit | Stacked AreaChart `debt` + `available`, `stackId="credit"` (D-11); both converted in primary mode (D-12) |
| Primary mode FX gap | Skip point when FX null; leave gap (`connectNulls={false}`) (D-16) |
| Partial NW days | Still plot; **no** badge/tooltip marker (D-14) |
| Sampling | Event dates ∪ today only — never daily densify (D-07) |
| Window | `30d`/`90d` = calendar days back from Moscow `today`; `1y` = 365 calendar days; `all` = no start bound (06-RESEARCH A4) |
| Height | `ChartContainer` `className="h-[200px] w-full"` |
| Money boundary | Majors as `number` at chart props; BigInt never crosses RSC→client |
| Out of scope | Assets vs liabilities chart (NW-04); `/accounts` expand charts; snapshot CRUD on home; new nav item |
