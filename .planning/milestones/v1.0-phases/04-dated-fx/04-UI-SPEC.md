## Typography

Exactly four sizes, two weights (400 + 600) — **inherited from Phase 02**:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.5 |
| Heading | 24px | 600 | 1.2 |
| Display | 30px | 600 | 1.2 |

Usage (Phase 04 extensions):
- **Heading** — page title «Валюты» (unchanged; tabs switch content under it).
- **Body** — currency code as row primary on rates list; set-rate dialog description; empty/error body; tab inactive text.
- **Label** — form labels; LOCF meta (rate + as-of date); history row date/rate; direction toggle labels; active tab underline companion text may stay Body with weight 600 only via component/nav pattern — prefer Label/Body 400 + accent underline for active tab (match top-nav active treatment).
- **Display** — not used on currencies/rates this phase.

Rates (decimal), as-of dates, and currency codes use Geist Mono at Label size; weight 400 only (600 reserved for headings/CTA text weight on buttons via component default).

Sources: Phase 02/03 UI-SPEC; rates surfaces only.

## Color

Light theme tokens — **inherited from Phase 02** (`src/app/globals.css` `:root`):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`--background`) | Page background, dialog surface, rate row default |
| Secondary (30%) | `#F5F5F5` (`--muted` / `--secondary`) | Top nav, row hover, **expanded history panel** (`bg-muted/40` or muted fill), inactive direction side |
| Accent (10%) | `#1A1A1A` (`--primary`) | Reserved elements only (see below) |
| Destructive | `#C4473A` (`--destructive`) | History **Удалить** control text/icon; field `aria-invalid` / error text; confirm destructive affordance |

Accent reserved for:
1. Primary CTA buttons («Задать первый курс», dialog «Сохранить курс», existing currency «Добавить валюту» / «Сохранить»)
2. Active top-nav link underline/foreground emphasis
3. Active currencies-area tab underline/foreground emphasis («Курсы» or «Валюты»)
4. Focus ring companion (`--ring`) on focused controls
5. Phase 02 «Основная» badge (unchanged on currency list tab)
6. Active side of direction toggle (filled/`default` or clear selected state)

Do **not** use accent for: every list row, borders, expand chevrons, plain history rows, inactive tabs, or decorative icons.

Destructive reserved for: FX rate delete control + its confirmation; validation error text. Never for set-rate primary submit.

Foreground: `--foreground` ≈ `#0A0A0A`. Muted meta (as-of date, «Нет курса» secondary): `--muted-foreground` ≈ `#737373`.

Sources: Phase 02/03 UI-SPEC; destructive for history delete (D-13).

### Set-rate Dialog

| Dialog | Title |
|--------|-------|
| Set / upsert rate | Задать курс |

| Field | Label |
|-------|-------|
| Other currency | Валюта |
| Direction | Направление |
| Rate amount | Курс |
| As-of date | Дата |

Direction toggle labels (dynamic codes; primary code from seed, e.g. RUB):
- Default (matches storage, D-06): `1 {OTHER} = N {PRIMARY}` — e.g. `1 USD = N RUB`
- Alternate (invert before write, D-05): `1 {PRIMARY} = N {OTHER}` — e.g. `1 RUB = N USD`

Until OTHER selected, show placeholders `1 … = N {PRIMARY}` / `1 {PRIMARY} = N …` or disable rate until currency chosen — prefer Select required first; default direction selected on open.

Muted hint under rate (optional Label): «Курс хранится как единиц основной валюты за 1 единицу выбранной.» — discretionary; not required if toggle labels are clear.

Date input: default **today** Europe/Moscow (D-08); `max` = today; past allowed; future forbidden. Display **DD.MM.YYYY**; form value `YYYY-MM-DD`.

Same-date overwrite: no extra confirm in dialog — upsert intended (D-11).

### Rate row LOCF display (populated)

**Visual focal (populated rates tab):** LOCF rate + as-of meta (`{rate}` · `на {DD.MM.YYYY}`) is the primary visual anchor per row. Accent CTA appears only for empty «Нет курса» rows («Задать первый курс»).

| State | Display pattern |
|-------|-----------------|
| Has LOCF today | `{CODE}` · `{rate}` {PRIMARY} · `на {DD.MM.YYYY}` — rate is primary-per-1-other (storage direction), Geist Mono |
| No rates | `{CODE}` · «Нет курса» + «Задать первый курс» |

Never show raw scaled BigInt. Never invent `1.00` / `0.00` when LOCF null (D-15).

Primary currency never appears as a rates-list row (D-16).

## Interaction & Layout Contract

| Decision | Contract |
|----------|----------|
| Routes | `/currencies` = list tab; `/currencies/rates` = rates tab (D-04). **No** top-level `/fx` (D-01) |
| Tabs | Link underline tabs in `currencies/layout.tsx` — not parallel `@` slots; not required to install shadcn Tabs |
| Nav | Top «Валюты» → `/currencies/rates`; active on pathname starting with `/currencies` |
| Set rate | Per-row (or shared) Dialog: currency Select + direction + rate + as-of (D-05–D-09). Remount form on open (`formKey`) like SetBalanceDialog |
| Currency picker | All non-primary currencies even with zero accounts (D-07); filter `isPrimary: false`; server rejects primary |
| Direction | UX only; always persist `rateToPrimaryScaled`; default `toPrimary` / «1 other = N primary» (D-05, D-06) |
| Default date | Today via `calendarDateToday("Europe/Moscow")`; pass as prop from server |
| First rate | Emphasized accent Button «Задать первый курс» when no rates (D-14) |
| Current LOCF | One row per non-primary: LOCF-as-of-today rate + producing as-of date (D-10) |
| History | Inline expand under currency rate row (`useState`); not Sheet/Dialog history |
| Expand affordance | Ghost icon Button + lucide `ChevronRight` (collapsed) / `ChevronDown` (expanded); 44×44 tap target |
| Delete | Only on history rows (D-13); never inside set-rate Dialog. Confirm before delete (copy above) |
| Pending submit | Disable primary button; keep Dialog open until success then close + `revalidatePath("/currencies")` and `revalidatePath("/currencies/rates")` |
| Pending delete | Disable that row’s delete control while action pending |
| Rate I/O | Major decimal string ↔ parse/format at scale 8 (`RATE_SCALE_E8`); invert via integer helper when direction is fromPrimary |
| BigInt boundary | Serialize `rateToPrimaryScaled` as string to client components |
| Out of scope UI | No amount convert/preview calculator (D-17); no API fetch (FX-03); no other↔other pairs |
