## Typography

Exactly four sizes, two weights (400 + 600). Match Phase 02 / 20 / accounts shell.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.5 |
| Heading | 24px | 600 | 1.2 |
| Display | 30px | 600 | 1.2 |

Usage:
- **Display** — not used on `/accounts` SAVINGS surfaces.
- **Heading** — page title «Счета» only (unchanged shell). Dialog titles use Body/Label-sized `DialogTitle` per existing shadcn dialog (do not bump to Heading).
- **Body** — account name (list primary); dialog description; empty-state body; form-level errors.
- **Label** — form labels («Название», «Тип», «Валюта», «Годовой %», «День начисления»); list secondary meta (type · CCY · rate · countdown); muted read-only type/currency on edit.

Currency **codes**, **rate %** (`16.50%`), and **DOM** input digits may use Geist Mono at Label/Body size; weights still 400 or 600 only.

Sources: Phase 02 Typography; existing AccountList `text-base` / `text-sm`.

### List secondary line (SAVINGS)

Format under account name (Label size, `text-muted-foreground`), segments joined by ` · `:

1. Type: **Накопительный**
2. Currency code (mono)
3. Rate: `{formatBpsToPercentMajor(bps)}%` e.g. `16.50%` (dot; include trailing zeros from scale-2 formatter)
4. Countdown: **`сегодня`** if next accrual calendar day === Moscow `today`; else **`через N дн.`** for N ≥ 1 (compact; no full pluralization required)

**Forbidden on list:** raw accrual day-of-month integer (D-12). Raw DOM only in create/edit form fields.

LOCF balance line (existing asset pattern) stays below secondary meta — unchanged for SAVINGS principal.

## Interaction & Layout Contract

| Decision | Contract |
|----------|----------|
| Routes | `/accounts` only for this phase UI; no new routes; Капитал NW inclusion is data-only (no new chrome) |
| Create/edit | Extend existing `AccountFormDialog` Dialog — no `/new` or `/[id]/edit` (D-08) |
| Create type options | `ASSET` · `FIAT_CREDIT` · **`SAVINGS`** (labels Актив / Кредитный / Накопительный) |
| Type-gated fields | Rate + DOM visible **only** when create type = `SAVINGS` (mirror credit-limit gate for `FIAT_CREDIT`) — D-10 |
| Edit SAVINGS | Same dialog shows editable **Название** + **Годовой %** + **День начисления**; prefill from `annualRateBps` / `accrualDayOfMonth` |
| Edit non-SAVINGS | Name editable; type/currency read-only; credit limit read-only for FIAT_CREDIT (existing); **no** rate/DOM fields |
| Immutable after create | Type and currency **forever locked** — server ignores client type/currency on edit (D-08) |
| Rate I/O | UI major percent string ↔ persist `annualRateBps` Int via scale-2 money helpers (D-01); never show raw bps in UI |
| Accrual calendar | List countdown uses `clampDayOfMonth` + Moscow `today` injected from page (display-only helper) |
| Balance snapshots | `SetBalanceDialog` / history / delete — **unchanged**; works for SAVINGS like ASSET (D-16); no auto interest write |
| Out of scope UI | Interest amount, «Прогноз» overlay, MCP fields — Phases 28–30 |
| Pending submit | Disable primary button; keep Dialog open until success then close + revalidate |
| Dialog width | Existing `sm:max-w-md` |
