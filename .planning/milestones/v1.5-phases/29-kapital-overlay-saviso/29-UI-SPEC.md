All new chrome is Russian. Currency codes stay Latin as stored. One series name: **«Прогноз»**.

| Element | Copy |
|---------|------|
| Primary CTA | *(none — overlay is display-only. Range labels stay «30д» / «90д» / «1г» / «всё»)* |
| Empty state heading | *(none — hide the dashed series when no FX-included slot; fact chart stays)* |
| Empty state body | *(none — no toast, no empty card)* |
| Error state | *(no submit error. Missing FX uses the partial banner below)* |
| Destructive confirmation | *(none)* |

### Forecast chrome

| Element | Copy | When |
|---------|------|------|
| Legend / Line `name` | Прогноз | One legend entry. No split by income / interest / grace |
| Future tooltip — level | Прогноз + level | `asOfDate > today`. Level is a NW figure, primary currency |
| Future tooltip — interest header | Накопительный | Once, when that point has ≥1 interest event |
| Future tooltip — interest subtitle | Ожидаемое начисление | Once under the header. Not repeated per row |
| Interest row | `{accountName}` + `+{amount}` | One row per SAVINGS account, accrual day only |
| Future tooltip — grace header | Платёж для беспроцентного | When that point has ≥1 grace event. After the interest block |
| Future tooltip — grace subtitle | Ожидаемый платёж | Once under the header. Retire «NW без изменения (оплата карты)» |
| Grace row | `{accountName}` + `-{amount}` | One row per obligation. Amount is the payment |
| Today tooltip | Account stack + Итого, then grace block if any | Interest block is absent on `asOfDate <= today` |
| Partial banner | Прогноз неполный · нет курса {CODES} | Any dropped income, interest, or grace slot |

**Amount glyphs (ASCII, no extra space):**

| Figure | Render |
|--------|--------|
| Interest row | `+` + `formatChartNumber(displayPrimaryMajor)` → `+1 234` |
| Grace row | `-` + `formatChartNumber(displayPrimaryMajor)` on the **positive** major → `-1 234` |
| «Прогноз» level | `formatChartNumber(forecastVal)` only. `0` stays `0`. A leading `-` appears only when the level itself is negative |

**Interest row sort:** `displayPrimaryMajor` descending, then `accountName` via `localeCompare(name, "ru", { sensitivity: "base" })`. Equal amount and equal base name keep builder order (stable). Probe: amounts 20 / 20 / 10 and names Альфа / Яндекс / Бета render Альфа, Яндекс, Бета.

**Missing name:** interest row falls back to `счёт {accountId}`. Grace row keeps the existing `обязательство {parentId}` fallback.

**FX banner:** `{CODES}` = unique missing codes, alphabetical, joined `", "`. One code: `· нет курса USD`. Codes only. No «накопительный», «грейс», «доходы», or other kind tag.

**Absent from the UI:**
- Running principal after the credit
- Sum of future credits through the horizon
- Delta versus the previous month
- The word «капитализация»
- «NW без изменения» and «NW без изменения (оплата карты)»
- A second legend entry or a second Line
- English «Forecast» / «Interest» / «Grace»
- Any MCP tool screen or description edit

Sources: CONTEXT D-01…D-13, C-01, C-03; 29-RESEARCH Pattern 3–4; locked_ui.

## Interaction & Layout Contract

| Decision | Contract |
|----------|----------|
| Surface | Капитал `/` only. No new route |
| Series | One dashed «Прогноз» Line in primary currency. Kind is tooltip-only |
| Line geometry | `dataKey="forecast"`; `type="stepAfter"`; `strokeDasharray="5 5"`; `stroke="var(--muted-foreground)"`; `strokeWidth={1.5}`; `dot={false}`; `connectNulls={false}`; `name="Прогноз"` |
| Interest on the line | Accrual day raises the running level by that day's primary credit. Later days stay at the higher level and do **not** repeat the interest row |
| Grace on the line | Due day **lowers** the running level by that payment's primary amount. Same stroke, same dash. No dip color, no marker |
| «Прогноз» figure | The level at that point. Not a delta. No plus prefix |
| Future tooltip order | (1) «Прогноз» level (2) interest block if events that day (3) grace block if events that day. One card |
| Interest row contents | Account name + primary amount with plus. This accrual day's credit only |
| Interest row day | Render only from that point's `forecastEvents` where `kind === "interest"`. Horizon end with no events shows the level only |
| Today hinge | Fact Areas and «Итого» stay historical NW. Dashed sample on today may sit lower when an overdue grace payment folds onto today. Do not copy the dipped forecast into fact `nw`. Do not paint the interest block on the today branch |
| Grace subtitle | One string change in `ForecastGraceTooltipBlock` covers future and today tooltips |
| Sort | Tooltip only. Builder / MCP event order stays unsorted by this display rule |
| Horizon | Range preset: `30d` / `90d` / `1y`; `all` → 1y |
| FX miss | Drop that slot. One banner. Codes only. Applies to interest and grace |
| Hide series | No FX-included slot → no Line. Banner still shows when exclusions exist |
| Isolation | Viewing the overlay writes no `BalanceSnapshot`. Historical NW is snapshot LOCF |
| MCP | No UI and no tool-copy change in this phase |

### Future tooltip DOM

```
┌─ tooltip card ──────────────────────────────┐
│ {formatted date}                            │
│ [swatch] Прогноз              {level}       │  ← no plus
│ ── interest, only if events that day ──     │  ← border-t
│   Накопительный                             │
│   Ожидаемое начисление                      │  ← once
│   {accountName}               +{amount}     │  ← amount desc, then А→Я
│ ── grace, only if events that day ──        │  ← border-t
│   Платёж для беспроцентного                 │
│   Ожидаемый платёж                          │  ← once; retired subtitle gone
│   {accountName}               -{amount}     │
└─────────────────────────────────────────────┘
```

Interest block DOM mirrors `ForecastGraceTooltipBlock`: one muted header, one muted subtitle, then rows (`flex`, name `min-w-0 flex-1 break-words`, amount `shrink-0 font-mono font-semibold tabular-nums`).
