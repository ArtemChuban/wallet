## Interaction & Layout Contract

| Decision | Contract |
|----------|----------|
| Series count | **One** dashed «Прогноз» Line for income + grace (C-02/C-03/D-08) |
| A′ paint | ΔNW=0 still **samples** due / folded-today dates so tooltip can open (D-06); Line stays flat across those points |
| Grace-only | `showForecast === true` when FX-included grace slots exist even if cumulative NW unchanged (D-07) |
| On-line markers | **No** distinct dots/colors/dash patterns for grace vs income days (D-08) |
| Forecast Line | Carry Phase 17: `dataKey="forecast"`; `strokeDasharray="5 5"`; `stroke="var(--muted-foreground)"`; `dot={false}`; `connectNulls={false}`; `type="stepAfter"` |
| ReferenceLine | Vertical at `x={today}`; `stroke="var(--border)"`; when forecast shown |
| Legend | Show when `accounts.length > 1 \|\| showForecast` — single «Прогноз» entry |
| Tooltip ≤ today | (1) Account stack + «Итого»; (2) if grace events on today → grace block below with C-04 copy + per-obligation rows (D-09/D-10/D-12) |
| Tooltip > today | (1) «Прогноз» + amount; (2) if grace events that day → grace block below (D-10). No fake account stack |
| Same-day income+grace | Two blocks **in one** tooltip card; order locked: forecast/income first, grace second (D-10) |
| Overdue OPEN | Folded to today sample; appear in **today** tooltip grace block — not past `dueAsOf` point (D-02/D-09) |
| Membership UX | CLOSED / early-closed absent (C-07); FX-miss absent from tooltip (D-13) |
| Horizon | Mirror range preset: `30d`/`90d`/`1y`; `all`→1y (C-06) |
| Partial banner | Quiet card under chart when any missing FX codes; list every unique code across income+grace (D-14…D-17) |
| Hide series | `includedSlotCount === 0` → no Line/legend; **still** show banner if exclusions (D-18) |
| Isolation | Overlay-only; UI never implies historical LOCF / BalanceSnapshot changed |
| Packages | Zero new npm; no new shadcn registry blocks |

### Tooltip DOM (discretion lock — D-10)

```
┌─ tooltip card ─────────────────────────────┐
│ {formatted date}                           │
│ ── block A (income / fact) ──              │
│   [today] stack rows… + Итого              │
│   [future] Прогноз · {amount}              │
│ ── block B (grace, if any events) ──       │  ← border-t separator
│   Платёж для беспроцентного                │
│   {accountName} · {amount}                 │  ← one row per OPEN
│   NW без изменения (оплата карты)          │  ← sub under each row or once under heading
│   …                                        │
└────────────────────────────────────────────┘
```

**Sub placement (discretion):** put «NW без изменения (оплата карты)» once under the grace heading when all rows share ΔNW=0, **or** repeat under each row — both satisfy C-04. Prefer **once under heading** to reduce clutter when many OPEN same day; amounts stay per-row (D-11/D-12).
