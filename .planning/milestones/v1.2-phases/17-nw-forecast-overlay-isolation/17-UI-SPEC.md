## Interaction & Layout Contract

| Decision | Contract |
|----------|----------|
| Chart parent | `ComposedChart` + stacked `Area` (fact) + dashed `Line` (forecast) — **not** AreaChart+hack (D-09; RESEARCH Pattern 3) |
| Forecast Line | `dataKey="forecast"`; `strokeDasharray="5 5"`; `stroke="var(--muted-foreground)"`; `dot={false}`; `connectNulls={false}`; `type="stepAfter"` (stair-step = D-04) |
| ReferenceLine | Vertical at `x={today}`; `stroke="var(--border)"`; always present when forecast series shown; ensure `today` + `horizonEnd` exist in merged `data[]` so hinge / future axis not discarded (D-07/D-12) |
| Legend | Show when `accounts.length > 1 \|\| showForecast` — «Прогноз» visible even with single account (D-10; RESEARCH Open Q2) |
| Tooltip ≤ today | Account stack rows + «Итого» NW — unchanged fact UX (D-11) |
| Tooltip > today | «Прогноз» + amount only; omit stack keys / fake fills (D-11) |
| Horizon | Mirrors range preset: `30d→+30`, `90d→+90`, `1y→+365`, `all→+365` (D-05); recompute on range change |
| Membership UX | No UI for filled/overdue/today slots — simply absent from series (D-02/D-03) |
| Hide series | `includedSlotCount === 0` → no Line, no «Прогноз» legend entry (D-08/D-16) |
| Partial banner | Quiet card near NW chart section when `isPartialForecast`; independent of account hero partial on same page |
| Isolation | Chart may merge forecast props; UI never implies past LOCF changed; no BalanceSnapshot writes from this chrome |
| Stats reuse | Forbidden — forecast ≠ `/income` CPTY stats UI |
| Packages | Zero new npm; no new shadcn registry blocks |
