## Typography

Exactly four sizes, two weights (400 + 600). Align with existing ready page (`text-3xl font-semibold` + body).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.5 |
| Heading | 24px | 600 | 1.2 |
| Display | 30px | 600 | 1.2 |

Usage:
- **Display** — ready-page hero title only (`/`).
- **Heading** — page titles on `/currencies` and `/accounts` («Валюты», «Счета»).
- **Body** — list primary text (account/currency name), empty/error body, dialog description.
- **Label** — form labels, table column headers, muted meta (code, type, scale, primary badge text).

Currency **codes** and numeric **scale** may use Geist Mono at Label/Body size; weight still 400 or 600 only.

Sources: Phase 1 `page.tsx` patterns; design-contract defaults for line-height.

## Color

Light theme tokens from `src/app/globals.css` `:root` (Phase 1 shadcn neutral). Use CSS variables in implementation; hex below are approximate contracts for checker/visual QA.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`--background` oklch(1 0 0)) | Page background, dialog surface |
| Secondary (30%) | `#F5F5F5` (`--muted` / `--secondary` oklch(0.97 0 0)) | Top nav bar, list row hover/zebra, muted meta chips |
| Accent (10%) | `#1A1A1A` (`--primary` oklch(0.205 0 0)) | Reserved elements only (see below) |
| Destructive | `#C4473A` (`--destructive` oklch(0.577 0.245 27.325)) | Not used for actions in Phase 2; reserved for field `aria-invalid` / error text only |

Accent reserved for:
1. Primary CTA buttons («Добавить валюту», «Добавить счёт», «Сохранить»)
2. Active nav link underline/foreground emphasis
3. Focus ring companion (`--ring`) on focused controls
4. «Основная» primary-currency badge foreground on filled/emphasis chip (badge fill stays secondary/muted)

Do **not** use accent for: every list row, borders, plain links in body copy, type labels, or decorative icons.

Foreground text: `--foreground` ≈ `#0A0A0A`. Muted copy: `--muted-foreground` ≈ `#737373`.

Sources: `globals.css`; 60/30/10 split default applied to existing neutral palette.

### Immutable-field UX (create vs edit)

- Create currency: editable **Код**, **Название**, **Масштаб (0–18)**; no primary toggle (create always non-primary).
- Edit currency: only **Название**; show code + scale as read-only text.
- Create account: **Название**, **Тип**, **Валюта**; if type = Кредитный show **Кредитный лимит** (major units) + hint «в единицах выбранной валюты».
- Edit account: only **Название**; type, currency, credit limit read-only.
- Primary currency row: badge «Основная»; no delete control anywhere.

Sources: D-17–D-20; RESEARCH Russian type map + Zod messages; yolo empty/error defaults.

## Interaction & Layout Contract

| Decision | Contract |
|----------|----------|
| Routes | `/currencies`, `/accounts`; keep `/` ready/status (D-17, D-19) |
| Nav | Simple **top** horizontal nav in root layout (RESEARCH A3); Russian labels above |
| Create/edit | **Dialog** overlays on list pages — no `/new` or `/[id]/edit` routes (D-18) |
| Lists | Server-rendered tables or stacked rows: name primary; meta (code/scale/type/currency/limit) secondary Label size |
| Credit limit display | Format via `formatMinorToMajor` + currency code (e.g. `500000.00 RUB`); never show raw minor BigInt |
| Credit limit input | Major-unit decimal string; parse with currency `scale` via `parseMajorToMinor` |
| Pending submit | Disable primary button; keep Dialog open until success then close + revalidate |
| No delete UI | Do not render delete buttons, menus, or confirmations |
