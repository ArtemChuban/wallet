## Typography

Exactly four sizes, two weights (400 + 600). Match Debts / Phase 09.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.5 |
| Heading | 24px | 600 | 1.2 |
| Display | 30px | 600 | 1.2 |

Usage:
- **Display** — not used on `/income` (no totals hero this phase).
- **Heading** — page title «Доходы» (`text-2xl font-semibold`).
- **Body** — person names in group headers; empty/error body; dialog description; honesty subtitle; planned amount on row (`font-mono` OK).
- **Label** — form labels; compact row meta (type label, currency code, planned date); muted empty-group copy.

Currency **codes**, formatted money, and **YYYY-MM-DD** planned dates may use Geist Mono at Label/Body size; weights still 400 or 600 only.

Empty-state title inside list uses Body size at weight **600** (`text-base font-semibold`), not Heading — page title remains sole Heading.

Page honesty line (D-11): Body or Label, `text-muted-foreground`, under/beside title — not Display.

Sources: Phase 09 UI-SPEC; `src/app/debts/page.tsx`; DebtsList empty chrome.

## Color

Light theme tokens from `src/app/globals.css` `:root` (shadcn neutral). Use CSS variables in implementation; hex below are approximate contracts for checker/visual QA.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`--background` oklch(1 0 0)) | Page background, dialog surface, list surface |
| Secondary (30%) | `#F5F5F5` (`--muted` / `--secondary` oklch(0.97 0 0)) | Top nav bar (`bg-muted/60`), empty-group inset (`bg-muted/30`), dashed empty page chrome |
| Accent (10%) | `#1A1A1A` (`--primary` oklch(0.205 0 0)) | Reserved elements only (see below) |
| Destructive | `#C4473A` (`--destructive` oklch(0.577 0.245 27.325)) | Delete entry controls, confirm-step primary, `aria-invalid` / error text |

Accent reserved for:
1. Primary CTA buttons («Новый человек», «Новый доход», dialog create/save submits)
2. Active nav link underline/foreground emphasis (including «Доходы» when pathname under `/income`)
3. Focus ring companion (`--ring`) on focused controls

Do **not** use accent for: every income row, person headers, type labels, borders, kind-toggle idle state, or decorative icons.

Do **not** introduce overdue/warning semantic color (amber/red row chrome) — Phase 15 owns overdue «заполни» (D-09, D-10). Past next-planned dates render as **normal** muted/foreground date text.

Destructive reserved for: person delete, income-source delete + their confirm-step buttons; validation error text. Never for create/rename primary submit.

Foreground text: `--foreground` ≈ `#0A0A0A`. Muted copy: `--muted-foreground` ≈ `#737373`. Borders: `--border`.

Sources: `globals.css`; Phase 09 60/30/10; CONTEXT D-09/D-10; DestructiveConfirmStep constitution.

### Compact income row (D-04, D-12)

Show only: type label (`Ежемесячный` / `Разовый`) + formatted planned amount (`formatMinorToMajor`) + currency code + next planned date (`YYYY-MM-DD` or `formatAsOfDisplay`). **No** truncated note on the row. **No** row-click-to-edit / detail dialog — only «Изменить» button.

### Locked fields on edit (RESEARCH A1 / debts parity)

Show as read-only text (not hidden): person name, currency code, kind. Editable: planned amount; recurring `dayOfMonth` + `startAsOf`; one-time `plannedAsOf`; note. Delete control only inside edit dialog. Kind cannot switch on edit (definition already one model).

### Create defaults (D-08)

- Kind = **Ежемесячный** (recurring)
- Currency = **primary** currency code (not first-by-code sort)
- Recurring `startAsOf` default = Moscow today (`calendarDateToday("Europe/Moscow")`) — field visible as «Начало с»

### Page header CTAs (D-15)

When ≥1 person exists: show both «Новый человек» and «Новый доход» in the page header (parity with debts). When zero people: empty-state CTAs cover create paths; do not duplicate a crowded header.

Honesty copy (D-11) always visible in header region when the page renders (including empty state).

| Pre-fill Person | In-group CTA sets `defaultPersonId`; user may change (D-06) |

| Edit | «Изменить» on row only — **not** row-click-to-edit (D-12); no DebtDetailDialog analog |
| Out of scope UI | Record actual, overdue «заполни», variance, closed-section chrome, pause/`endAsOf`, destination account, NW forecast, per-Person stats, totals hero |
| Destructive UX | `DestructiveConfirmStep` only — never `window.confirm` (UI-01) |
| Person delete Restrict | Block when **debts OR income** refs exist; dual `revalidatePath("/income")` + `revalidatePath("/debts")` (D-16) |
| Isolation | Income actions never write `BalanceSnapshot` / never import `@/lib/net-worth` or `@/lib/historical-series` |
| Page shell | `force-dynamic` RSC + `max-w-3xl` main like debts; pass serializable BigInt strings to client list |
| Pending submit | Disable primary; keep Dialog open until success → close + refresh/`revalidatePath("/income")` |
| Wave-0 test flip | Replace Phase 13 UI-00 (`src/app/income` must not exist) before creating route |
