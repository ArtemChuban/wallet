## Typography

Exactly four sizes, two weights (400 + 600). Match Phase 14 / Debts / Phase 09.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.5 |
| Heading | 24px | 600 | 1.2 |
| Display | 30px | 600 | 1.2 |

Usage:
- **Display** — not used on `/income` (no totals hero; Phase 16 territory).
- **Heading** — page title «Доходы» only.
- **Body** — person names; dialog description; planned/actual amounts on row (`font-mono` OK); live Δ amount in dialog.
- **Label** — form labels; type/currency/date meta; «заполни» badge text; variance RU phrase («больше плана» / «меньше плана» / «как план»); muted RO plan fields in fact dialog.

Currency **codes**, formatted money, **YYYY-MM-DD** dates, and **Δ** numeric may use Geist Mono at Label/Body size; weights still 400 or 600 only.

«получено» status on one-time filled row: Label size, weight **600**, `text-muted-foreground` (status chrome, not Heading).

Sources: Phase 14 UI-SPEC; CONTEXT D-07/D-12/D-14.

Chip pattern (no Badge component):  
`<span className="… rounded-md bg-warning/15 px-2 py-1 text-sm font-semibold text-warning-foreground">заполни</span>`

Accent reserved for:
1. Primary CTA buttons — overdue create **«Заполни»** (filled primary); page header «Новый человек» / «Новый доход»; fact-dialog submit when create/edit saves (same primary as other forms)

- Δ > 0 («больше плана») → `text-foreground` (neutral; not success-green invent)
- Δ < 0 («меньше плана») → `text-foreground` (neutral; not destructive — under-plan is informational)

Foreground: `--foreground` ≈ `#0A0A0A`. Muted: `--muted-foreground` ≈ `#737373`. Borders: `--border`.

Sources: Phase 14 Color; CONTEXT D-08/D-09/D-10; RESEARCH amber/`--warning` recommendation; shadcn theming extension (A1).

## Copywriting Contract

All chrome Russian. Currency codes stay Latin as stored. Phase 14 copy remains in force for definition/person chrome; this section adds fact/overdue/variance and restates row CTAs that change.

| Element | Copy |
|---------|------|
| Primary CTA (overdue create) | Заполни |
| Primary CTA (non-overdue create) | Внести факт |
| Primary CTA (edit existing actual) | Изменить факт |
| Overdue badge | заполни |
| One-time filled status | получено |
| Empty state heading (no people) | Нет людей |
| Empty state body (no people) | Добавьте человека или создайте доход, чтобы вести учёт. |
| Error state (fact form submit) | Не удалось сохранить факт. Проверьте поля и попробуйте снова. |
| Error state (actual amount ≤ 0) | Сумма должна быть больше нуля |
| Error state (invalid date) | Укажите корректную дату |
| Error state (delete actual failure) | Не удалось удалить факт. Попробуйте снова. |
| Destructive confirmation (delete actual) | Удалить факт получения? Слот снова станет пустым и может показать «заполни», если план в прошлом. Это нельзя отменить. |

### Variance phrases (D-14) — source currency only

| Condition | Copy |
|-----------|------|
| delta > 0 | больше плана |
| delta < 0 | меньше плана |
| delta = 0 | как план |

List/dialog show: plan amount, actual amount, signed Δ (actual − plan) + phrase above. No primary-FX conversion (D-13).

### Dialog titles

| Dialog | Title |
|--------|-------|
| Create fact (overdue or calm) | Внести факт |
| Edit fact | Изменить факт |
| Delete fact confirm | Удалить факт |

### Dialog actions

| Action | Label |
|--------|-------|
| Submit create (overdue row entry) | Заполни |
| Submit create (non-overdue) | Внести факт |
| Submit edit | Сохранить факт |
| Dismiss create/edit | Не сохранять |
| Enter delete-actual flow | Удалить факт |
| Confirm delete actual (second step) | Удалить факт |
| Back from confirm step | Назад |

Row CTA that **opens** the dialog uses the same labels as D-17: overdue → «Заполни»; non-overdue unfilled → «Внести факт»; hasActual → «Изменить факт». Definition row control remains «Изменить» (Phase 14).

### Fact form field labels (RU) — D-02, D-16

| Field | Label | Mode |
|-------|-------|------|
| Plan date (RO) | План · дата | Read-only text |
| Plan amount (RO) | План · сумма | Read-only text (`font-mono` + currency code) |
| Actual amount | Факт · сумма | Required input |
| Actual date | Факт · дата | Required date (`actualAsOf`) |
| Note | Заметка | Optional |
| Live Δ preview | Отклонение | Read-only: formatted Δ + variance phrase (updates while typing amount) |

### Compact income row chrome (Phase 15 delta)

Keep Phase 14 base: type label + planned amount + currency + next planned date. **Additions:**

| Row state | Extra chrome |
|-----------|--------------|
| Next open overdue (`isIncomeOverdue`) | Badge «заполни» + primary Button «Заполни» + keep «Изменить» definition |
| Next open not overdue, no actual | Outline Button «Внести факт» + keep «Изменить»; **no** badge |
| One-time with actual (D-07, D-18) | Status «получено»; inline plan + actual + Δ + phrase; Button «Изменить факт»; keep «Изменить» definition (plan immutable server-side after actual) |
| Recurring after fill | Row advances to new next open — **no** filled-month residual row; **no** list Δ for that filled month (D-07) |

**No** truncated note on the row. **No** row-click-to-edit. **No** multi-slot expand/chevron. **No** Recharts.

### Defaults (D-03, D-19)

- First-fill: actual amount = planned amount for slot; `actualAsOf` = Moscow today (`calendarDateToday("Europe/Moscow")`) — **never** default to plan date.
- Re-open edit: prefill from existing actual.
- Amount must be **> 0** (positive minor). `actualAsOf` any valid calendar date (past/future OK). Note optional, max 500.

### Carry-forward Phase 14 strings (unchanged)

Page title/nav «Доходы»; honesty «Учёт доходов не меняет остатки на счетах.»; kind labels «Ежемесячный» / «Разовый»; definition/person CTAs and delete copy from 14-UI-SPEC remain authoritative.

Sources: CONTEXT D-01..D-20; REQUIREMENTS ACT-01..03; 14-UI-SPEC copy tables; RESEARCH live-Δ recommendation.
