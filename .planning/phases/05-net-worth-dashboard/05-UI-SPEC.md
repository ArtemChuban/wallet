## Spacing Scale

Declared values (must be multiples of 4) — **inherited from Phase 02**:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Compact row gaps, hero label-to-amount gap |
| md | 16px | Default element spacing, list row padding-x, partial-warning padding |
| lg | 24px | Section padding, gap between hero and account list |
| xl | 32px | Layout gap between page top and hero; page `gap-8` main rhythm |
| 2xl | 48px | Gap between partial-warning banner and list when both present |
| 3xl | 64px | Not used on dashboard (former ready-page rhythm retired) |

Exceptions:
- Minimum tap target **44×44px** for empty-state CTA `Button` (labeled — default `h-8` OK with padding).
- Partial-warning callout: padding **16px** (md) vertical × **16px** (md) horizontal; **16px** (md) margin below hero, **24px** (lg) margin above list.
- Account list row: **12px** vertical (`py-3`) × **16px** horizontal (`px-4`) — match `/accounts` row density.

Source: Phase 02 UI-SPEC; dashboard layout exceptions.

## Typography

Exactly four sizes, two weights (400 + 600) — **inherited from Phase 02**:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.5 |
| Heading | 24px | 600 | 1.2 |
| Display | 30px | 600 | 1.2 |

Usage (Phase 05 extensions):
- **Display** — hero net-worth amount only (`font-mono text-3xl font-semibold`); single focal number (D-05).
- **Label** — hero caption «Капитал» (`text-sm text-muted-foreground`); list column headers; partial-warning body; «нет баланса» / «нет курса» hints; credit «доступно»/«долг» sub-lines.
- **Body** — account name (truncate); empty-state heading/body; DB error body.
- **Heading** — not used as page `<h1>` on dashboard (hero uses Display + Label); section title «Счета» optional above list — if present, Heading 24px.

Amounts and currency codes use Geist Mono at Label or Display size; weight 600 only on Display hero amount.

Sources: Phase 02 UI-SPEC; 05-CONTEXT D-05–D-08.

## Color

Light theme tokens — **inherited from Phase 02** (`src/app/globals.css` `:root`):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`--background`) | Page background, list surface |
| Secondary (30%) | `#F5F5F5` (`--muted` / `--secondary`) | Top nav, list row hover (`hover:bg-muted/40`), partial-warning background (`bg-muted` or `bg-muted/60`) |
| Accent (10%) | `#1A1A1A` (`--primary`) | Reserved elements only (see below) |
| Destructive | `#C4473A` (`--destructive`) | Partial-warning foreground/icon border accent only — **not** for hero amount or row balances |

Accent reserved for:
1. Empty-state primary CTA («Перейти к счетам»)
2. Active top-nav link underline/foreground emphasis («Главная» on `/`)
3. Focus ring companion (`--ring`) on empty-state CTA
4. Phase 02–04 patterns unchanged on other routes

Do **not** use accent for: hero net-worth number, every list row, partial-warning fill (use secondary/muted), or decorative icons.

Partial-warning treatment: **callout banner** — `bg-muted` (or `bg-muted/60`), `border border-border`, optional lucide `AlertTriangle` at Label size in `text-foreground` (not destructive red fill). Warning text `text-foreground`; supporting detail `text-muted-foreground`. Honest partial NW — not error-page red.

Foreground: `--foreground` ≈ `#0A0A0A`. Muted meta (hints, credit debt secondary): `--muted-foreground` ≈ `#737373`.

Sources: Phase 02 UI-SPEC; 05-CONTEXT D-11 discretion (callout over toast).

## Copywriting Contract

All chrome Russian. Currency codes stay Latin. Amounts via `formatMinorToMajor` + code; never raw BigInt.

| Element | Copy |
|---------|------|
| Nav: home | Главная (`href="/"`) |
| Nav: currencies | Валюты (`href="/currencies/rates"`) |
| Nav: accounts | Счета (`href="/accounts"`) |
| Nav order | Главная · Валюты · Счета (D-04) — **remove** «Готовность» (D-01) |
| Hero label | Капитал (D-06) |
| Hero amount | `{amount} {PRIMARY}` — code only, no symbol/name (D-07); e.g. `1 234 567,89 RUB` |
| Partial total warning (heading) | Итог неполный |
| Partial total warning (body) | Не все счета учтены в сумме: у части счетов нет баланса или нет курса валюты. Задайте балансы на странице «Счета» и курсы на «Курсы». |
| Empty state heading | Нет счетов |
| Empty state body | Создайте первый счёт, чтобы увидеть капитал. |
| Empty state CTA | Перейти к счетам (`Link` → `/accounts`) (D-12) |
| DB / page load error | Не удалось загрузить данные. Проверьте базу данных и обновите страницу. |
| Row: no balance snapshot | нет баланса (muted Label; account still listed, excluded from total — D-09) |
| Row: no FX for non-primary | — · нет курса (em dash + muted hint; no link required — D-10) |
| Destructive confirmation | none — dashboard is read-only (D-16) |

### List column headers (screen-reader + visual)

| Column | Header |
|--------|--------|
| Name | Счёт |
| Native | В валюте счёта |

Implement as visually hidden `<th>`/`<caption>` or a single header row with Label typography above the list — executor choice; all three labels must be present for a11y.

### Account row display (populated, read-only)

| Account type | Native column | Primary column |
|--------------|---------------|----------------|
| FIAT_DEBIT / CRYPTO / CASH (has LOCF) | `{amount} {CODE}` | `{converted} {PRIMARY}` |
| FIAT_CREDIT (has LOCF) | `доступно {available} {CODE}` · `долг {debt} {CODE}` (mirror Phase 03 `LocfDisplay` without as-of date — D-15) | `долг {debtPrimary} {PRIMARY}` only — debt that reduces NW (D-15, ACCT-03) |
| Primary-currency account | same as asset row | identity — same numeric amount as native when included in total |
| No balance (any type) | нет баланса | — |
| Has balance, non-primary, no FX | `{amount} {CODE}` | — · нет курса |

No as-of date on dashboard rows (D-08: «current» = LOCF today; date omitted on rows for scanability). No type/limit meta line on dashboard (name + two balance columns only — D-14).

## Interaction & Layout Contract

| Decision | Contract |
|----------|----------|
| Route | **`/`** = net-worth dashboard Server Component; **remove** standalone DB readiness page (D-01, D-02) |
| Page shell | `main` with `mx-auto w-full max-w-3xl flex-1 flex-col gap-8 px-4 py-8` — match `/accounts` (code_context) |
| Nav | Update `src/components/nav.tsx`: first link «Главная» → `/`; drop «Готовность»; order Главная → Валюты → Счета (D-03, D-04) |
| Hero block | Top of page: Label «Капитал» + Display amount; **no** assets/liabilities split (D-05); **no** as-of subtitle (D-08) |
| Capital total | Sum included accounts only: assets (debit/crypto/cash LOCF) + credit debt as negative via `creditDebtMinor`; exclude accounts with null LOCF or missing FX for non-primary (D-09, D-10); primary-currency accounts need no FX row |
| Partial total | When ≥1 account excluded from sum, still render hero amount (partial NW) **and** partial-warning callout between hero and list (D-11) |
| Account list | Flat `ul` bordered like `AccountList`; **read-only** — no expand, no set-balance, no edit, no delete (D-13, D-16) |
| Row layout | Three columns: name (truncate, flex-1) · native (mono, Label/Body, right-aligned on `sm+`) · primary (mono, right-aligned). Stack on narrow viewports: name full width, balances on second line |
| Empty accounts | Zero accounts → empty state copy + CTA Link to `/accounts`; **no** hero amount (or hide hero — prefer omit hero block entirely when empty) |
| DB failure | `getDbReadiness` pattern from current `page.tsx` → on failure render Russian error copy in page shell; no separate `/` readiness UI (D-02) |
| Data fetch | Server Component: batch LOCF balances + FX rates for `calendarDateToday()` (Europe/Moscow); mirror `/accounts` + `/currencies/rates` batch patterns |
| Money I/O | `formatMinorToMajor`, `convertOtherMinorToPrimaryMinor`, `creditDebtMinor`; serialize BigInt as string at RSC boundary |
| Out of scope | Historical charts (Phase 6); assets/liabilities chart breakdown (NW-04); inline CRUD; FX deep link «Задать курс» (deferred); amount calculator (Phase 4 deferred) |
