## Typography

Exactly four sizes, two weights (400 + 600). Match Phase 02 / accounts list.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.5 |
| Heading | 24px | 600 | 1.2 |
| Display | 30px | 600 | 1.2 |

Usage:
- **Display** — not used on `/debts` (dashboard/ready heroes only).
- **Heading** — page title «Долги».
- **Body** — person names in group headers, empty/error body, dialog description, debt remaining amount.
- **Label** — form labels; compact debt-row meta (direction label, currency code); muted «Нет долгов»; read-only locked field captions.

Currency **codes** and formatted money may use Geist Mono at Label/Body size; weights still 400 or 600 only.

Empty-state title inside list uses Body size at weight **600** (same pattern as AccountList `text-base font-semibold`), not Heading — keep page title as sole Heading on the page.

Sources: Phase 02 UI-SPEC; `AccountList` empty chrome.

## Color

Light theme tokens from `src/app/globals.css` `:root` (shadcn neutral). Use CSS variables in implementation; hex below are approximate contracts for checker/visual QA.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`--background` oklch(1 0 0)) | Page background, dialog surface, list surface |
| Secondary (30%) | `#F5F5F5` (`--muted` / `--secondary` oklch(0.97 0 0)) | Top nav bar, person-group subtle separation / hover, muted chips, empty-group inset |
| Accent (10%) | `#1A1A1A` (`--primary` oklch(0.205 0 0)) | Reserved elements only (see below) |
| Destructive | `#C4473A` (`--destructive` oklch(0.577 0.245 27.325)) | Delete entry controls, destructive confirm primary, field `aria-invalid` / error text |

Accent reserved for:
1. Primary CTA buttons («Новый человек», «Новый долг», dialog «Сохранить» / «Создать»)
2. Active nav link underline/foreground emphasis (including «Долги» when pathname under `/debts`)
3. Focus ring companion (`--ring`) on focused controls

Do **not** use accent for: every debt row, person headers, direction labels, borders, or decorative icons.

Destructive reserved for: person delete, debt delete (inside edit dialog), balance-snapshot delete + their confirm-step buttons; validation error text. Never for create/rename primary submit.

Foreground text: `--foreground` ≈ `#0A0A0A`. Muted copy: `--muted-foreground` ≈ `#737373`.

Sources: `globals.css`; Phase 02/03 UI-SPEC 60/30/10; D-16 destructive constitution.

### Compact debt row (D-02)

Show only: direction label (`Я должен` / `Мне должны`) + formatted remaining (`formatMinorToMajor`) + currency code. No due date, note, or status chrome on the row.

### Locked fields on edit (D-09 / D-10)

Show as read-only text (not hidden): person name, currency code, initial amount (formatted major + code). Editable: direction, due date, note. Delete control only inside this dialog (D-14).

### Page header CTAs (D-22)

When ≥1 person exists: show both «Новый человек» and «Новый долг» in the page header. When zero people: empty state CTAs cover create paths (person and/or debt); do not duplicate a crowded header.

Sources: CONTEXT D-11, D-15, D-20–D-22; RESEARCH deletePerson sketch; Phase 03 snapshot confirm copy migrated off `window.confirm` (D-17).

## Interaction & Layout Contract

| Decision | Contract |
|----------|----------|
| Route | `/debts` only — no `/debts/[personId]` (D-01) |
| List structure | Grouped by person: person header + nested debt rows; include people with zero debts (D-03) |
| Sort | People A–Z by name; debts within group newest first by `id` (D-04) |
| Nav order | Главная · Счета · Долги · Валюты (D-18) |
| Nav active | «Долги» active for any pathname under `/debts` (prefix match) (D-19) |
| Create/edit | Dialog overlays — mirror `AccountFormDialog` (open/`formKey` remount) |
| Debt create person paths | Existing person Select **or** new-person name field in same dialog; one submit creates person+debt when new path (D-05, D-06) |
| Pre-select | «Новый долг» from a person group pre-selects that person; user may switch (D-12) |
| Remaining | Compute with `remainingMinor` on server; serialize string for client (BigInt boundary) |
| Destructive UX | Never `window.confirm`. In-dialog second step with RU loss copy (D-16). Migrate snapshot delete in `AccountList` (D-17). RateList `window.confirm` stays out of Phase 9 scope |
| Shared confirm helper | Prefer extract `DestructiveConfirmStep` if ≥2 call sites in same wave; else duplicate then extract (RESEARCH Q1 / discretion) |
| Pending submit | Disable primary button; keep Dialog open until success then close + `revalidatePath("/debts")` |
| Isolation | Do not import debt modules into `net-worth.ts`, `historical-series.ts`, or `/` (DISOL-01) |
| Out of scope UI | Repayments, close/write-off, status picker, charts, primary totals hero, filters/search |
