## Typography

Exactly four sizes, two weights (400 + 600). Match Phase 15 / Debts / Income.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 400 | 1.5 |
| Heading | 24px | 600 | 1.2 |
| Display | 30px | 600 | 1.2 |

Usage:
- **Display** — not used on grace surfaces (no totals hero).
- **Heading** — dialog title «Беспроцентный период» only (`DialogTitle`).
- **Body** — dialog description; obligation amounts; confirm messages; interest hint; empty-schedule / DOM-non-recalc hints.
- **Label** — form labels («Дата выписки», «Оплатить до», «Платёж для беспроцентного», «Заметка», «Дата оплаты»); status «К оплате» / «Оплачено»; CTA «Ввести сумму»; UX-01 amount disclaimer; AccountList «Грейс» button text; overdue chip on button.

Currency **codes**, formatted money, and **YYYY-MM-DD** / day-of-month inputs may use Geist Mono at Label/Body size; weights still 400 or 600 only.

Status «К оплате» on OPEN row: Label size, weight **600**, default foreground (or warning pair when overdue).  
Status «Оплачено» in collapsed history: Label size, weight **400**, `text-muted-foreground`.

Sources: Phase 15 Typography; Phase 18 D-14…D-18; 20-CONTEXT D-16.

## Color

Light theme tokens from `src/app/globals.css` `:root` (shadcn neutral) **including existing warning tokens** (already shipped for income overdue). Hex below are approximate contracts for checker/visual QA.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`--background` oklch(1 0 0)) | Page `/accounts`, dialog surface, list surface |
| Secondary (30%) | `#F5F5F5` (`--muted` / `--secondary` oklch(0.97 0 0)) | Top nav; muted hints; collapsed CLOSED section inset |
| Accent (10%) | `#1A1A1A` (`--primary` oklch(0.205 0 0)) | Reserved elements only (see below) |
| Warning | `#B45309` foreground / soft fill (`--warning` ≈ oklch(0.75 0.15 75); `--warning-foreground` ≈ oklch(0.45 0.14 55)) | Overdue OPEN row chrome + grace-button mark + interest hint — calendar urgency, **not** validation error |
| Destructive | `#C4473A` (`--destructive` oklch(0.577 0.245 27.325)) | Close/reopen confirm buttons via `DestructiveConfirmStep`; validation / action error text (`role="alert"`) |

Overdue OPEN row pattern (mirror IncomeList overdue chip tone):  
`bg-warning/15 text-warning-foreground` on the **obligation row inside grace dialog** + short interest hint beneath or beside due date.  
Grace button mark: small warn chip/dot on the **«Грейс» button only** when any OPEN obligation is overdue (`isGraceOverdue`). **Never** apply warning/destructive to whole account row name / LOCF «Задолженность» (D-07 / UX-01).

Accent reserved for:
1. Primary schedule save button in grace dialog («Сохранить расписание»)
2. Primary amount-dialog submit («Сохранить платёж» create/edit)
3. Primary CTA «Ввести сумму» on candidate windows lacking a row
4. Active nav link on `/accounts` (existing shell)
5. Focus ring companion (`--ring`) on focused controls

Do **not** use accent fill for: outline «Грейс» entry (default `outline`/`sm` unless overdue mark present); «Показать оплаченные» toggle; «Оплачено» entry (outline or secondary — confirm step owns destructive); every credit row.

Do **not** use destructive for overdue chrome (OBL-03). Destructive reserved for DestructiveConfirmStep confirms + `aria-invalid` / error text only.

Foreground: `--foreground` ≈ `#0A0A0A`. Muted: `--muted-foreground` ≈ `#737373`. Borders: `--border`.

Sources: Phase 15 Color; globals.css warning tokens; 20-CONTEXT D-07; 20-RESEARCH overdue chrome.

## Interaction Contract (phase-specific)

> Prescriptive layout for executor. Complements copy table.

### Surfaces

1. **AccountList (FIAT_CREDIT only):** `outline`/`sm` button **«Грейс»** on the credit row (D-02). If any OPEN obligation overdue → warn mark on **that button only** (D-07). Whole-row click still does not open grace (existing edit remains separate).
2. **CreditGraceDialog:** opened from «Грейс». Top = dual DOM schedule form + hints (D-03/D-04/D-13/D-15). Below (only when schedule saved) = hybrid list (D-05/D-06/D-08). Close/reopen = in-dialog `DestructiveConfirmStep` steps (D-11/D-12).
3. **CreditGraceAmountDialog:** sibling dialog from CTA «Ввести сумму» or OPEN «Изменить» (D-09/D-10). No close/reopen here.

### Hybrid list rules

- Merge `resolveCurrentAndNext(schedule, today)` with persisted obligations by `cycleStartAsOf`.
- Missing window → CTA row «Ввести сумму» — **never** invent DB placeholder (D-05).
- Persist OPEN rows always listed (including overdue OPEN when `current` is null on gap day — Pitfall 7).
- Sort OPEN: overdue first → nearest `dueAsOf` → `cycleStartAsOf` (D-08).
- CLOSED behind collapsed «Показать оплаченные» (D-06).
- Clear schedule: enabled only when OPEN count = 0; CLOSED may remain; UI returns to empty-schedule hint + collapsed paid history (D-14).

### Confirm UX

- Early close: «Оплачено» → DestructiveConfirmStep + `children` = date input «Дата оплаты» (default today) + `pendingLabel="Сохранение…"`.
- Reopen: confirm message above + `pendingLabel="Возврат…"`.
- No `window.confirm`.

### Planner must_haves lift (explicit)

Truths (covered):
1. Empty schedule shows DOM fields + hint immediately; cycles only after save.
