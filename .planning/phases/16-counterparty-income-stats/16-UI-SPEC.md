### Stats chrome (Person group header) — locked microcopy

| Element | Copy | When |
|---------|------|------|
| Window hint | за всё время | Person has ≥1 actual; Label muted above/beside amount stack (D-15). Prefer this over bare «всего» — clearer all-time vs «this month». |
| Native line | `{formatMinorToMajor} {CODE}` | One line per currency in `nativeByCurrency` (D-07) |
| Primary line | `{formatMinorToMajor} {PRIMARY_CODE}` | See **Identity-omit rule** below |
| Partial line | Итог неполный · нет курса | `isPartial === true` on that Person only (D-08, D-11). Compact — **no** per-fact excluded list; **no** long «Задайте курсы…» paragraph in header (debts page hero keeps the long form; income stays one line). |
| Partial `role` | `status` | Announce partial without stealing focus |

**Do not ship:** «всего получено» page hero; page-level partial banner; period picker labels; debt «Я должен» / «Мне должны»; invented «0 {PRIMARY}» when FX missing.

### Identity-omit rule (D-06 amendment — Discretion lock)

D-06 says both rows always visible. Discretion + RESEARCH A1 amend:

**Omit the primary secondary line** when **all** are true:
1. `nativeByCurrency.length === 1`
2. That currency **is** the app primary
3. `!isPartial`

**Show the primary line** when any of: multi-currency natives; any non-primary native present; `isPartial === true`.

Rationale: avoid redundant identical numbers when native ≡ primary and rollup is complete. Partial never applies to primary-only facts in normal FX paths; if `isPartial` somehow true with primary-only natives, still show primary line for honesty.

Sources: CONTEXT D-01..D-15 Discretion; RESEARCH Open Q1 recommendation; DebtsPrimaryTotalsHero «Итог неполный» / page.tsx «нет курса».

## Interaction & Layout Contract

| Decision | Contract |
|----------|----------|
| Placement | Stats **inside** each Person group header on `/income` — not a separate «Статистика» page (D-10) |
| Header geometry | `flex` / `flex-wrap` / `items-start|center` / `justify-between` / `gap-4` (16px scale): **left** Person name; **center-right** stats block `text-right` (only if ≥1 actual); **far right** existing CTAs («Изменить имя» / «Удалить человека») |
| Native vs primary | Native stack larger (Body/semibold mono); primary one line under (Label/muted mono) when shown (D-06 + identity-omit) |
| Multi-ccy | One native line per currency (sorted by `currencyCode` asc for stability) + **one** rolled primary-Σ (D-07) |
| Membership | All-time actuals only (`actualAsOf` membership); recurring+one-time merged (D-01, D-02, D-13, D-14) |
| Plan-only Person | No stats block at all (D-03) — name + CTAs unchanged |
| Partial | Per-group only under that Person's amounts; never page hero / never global banner (D-04, D-11) |
| FX as-of | Display strings from RSC/pure helper using LOCF @ each fact `actualAsOf` — UI never invents rates (D-05, D-08) |
| Period UI | **No** month/YTD/from–to picker (D-13) |
| Global hero | **Forbidden** — do not mount `DebtsPrimaryTotalsHero` or any «всего получено» strip on `/income` |
| Chart | Do not mount `@/components/ui/chart` |
| Destructive | Unchanged Phase 14/15 |
| Isolation | Stats helpers/UI never write BalanceSnapshot / never import `@/lib/net-worth` or `@/lib/historical-series` |
| Serializable props | Pass formatted display strings (or minor strings + format on client consistently with existing list) — prefer RSC-formatted majors like debts totals |
